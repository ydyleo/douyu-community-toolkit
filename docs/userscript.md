# 小龟烂梗助手

## 本地使用

1. 在相邻的 `主播烂梗档案馆-api` 目录启动 PostgreSQL 和 Fastify API。
2. 在本前端目录执行 `npm run dev`。
3. 打开 `http://127.0.0.1:3000/userscripts/nishuixiaogui-meme-helper.user.js` 并在 Tampermonkey 中安装。
4. 打开任意斗鱼直播间；普通首页和分类页面不会显示助手。

脚本默认连接 `http://127.0.0.1:4000`。需要切换时，点击 Tampermonkey 菜单中的“设置小龟助手服务地址”，无需修改源代码。

## 使用方式

- 点击“小龟烂梗”打开或收起面板。
- 每次打开面板都会保留当前搜索词并重新请求最新烂梗，后台审核通过后收起再展开即可看到。
- 面板会读取最新热门标签；父标签带星号并排在独立标签前面，点击后可选择父标签本身或其子标签；也可以使用小型标签搜索框查找其他标签，再继续组合烂梗关键词搜索。
- 按住悬浮按钮或面板黄色标题栏可以拖动，位置会自动保存。
- 点击助手以外的网页区域即可收起面板，也可以使用右上角的关闭按钮。
- Tampermonkey 菜单可以临时隐藏或恢复助手，也可以重置助手位置；永久停用仍使用扩展自带的脚本开关。
- 从斗鱼首页或其他页面站内进入数字直播间时，助手会自动挂载；如果斗鱼页面重绘移除了助手，脚本也会自动恢复。异常时可使用 Tampermonkey 菜单中的“强制恢复小龟助手”。
- “一键发送”每次由用户主动触发，发送后有 3 秒本地冷却；单纯“填入”不触发冷却。
- 点击标题栏中的“投稿”，可以直接填写梗内容、分类、出处和标签；提交后进入后台待审核区，不会直接公开。
- 投稿标签沿用网站的父子标签结构，也可以填写一个建议新标签；未提交的内容会保存在油猴本地，提交失败不会丢失草稿。

## 正式发布

- `@downloadURL` 和 `@updateURL` 已指向 `https://9765366.cn/userscripts/nishuixiaogui-meme-helper.user.js`，版本号升级后 Tampermonkey 会自动检查更新。
- 生产环境对 `/userscripts/` 禁用强缓存，确保 Tampermonkey 能及时读取新版本号。
- `0.5.0` 起支持热门标签快捷筛选，并在结果中显示每条烂梗的标签。
- `0.5.1` 修复结果提示挤压热门标签栏的问题；搜索、筛选和复制后标签栏会保持显示。
- `0.6.0` 增加标签关键字搜索和匹配下拉框，非热门标签也可以直接查找并筛选。
- `0.6.1` 在复制或一键发送计数成功后立即更新助手卡片数字；网站打开期间通过轻量接口同步最新复制次数。
- `0.7.0` 统一父子标签排序和展开选择；只有复制会增加复制次数，一键发送不再重复计数。
- `0.7.1` 将成功填入弹幕框视为一次烂梗取用并计数；一键发送仍不重复计数。
- `0.7.2` 调整取用判定：单独填入不计数，成功一键发送计数一次；文字复制仍独立计数。
- `0.7.3` 修复无请求体的计数请求错误声明 JSON 类型、被 Fastify 返回 400 的问题。
- `0.7.4` 新增统一发布清单；网站显示版本与更新时间，助手发现新版时会显示更新入口。
- `0.7.5` 为烂梗搜索和标签搜索增加一键清空按钮，避免逐字删除。
- `0.7.6` 主动打开助手面板时立即检查更新，避免旧检查时间缓存延迟新版提醒。
- `0.7.7` 缩小搜索清空按钮，并改用 CSS 绘制居中的叉号。
- `0.7.8` 修正子标签命中时误显示不匹配父标签的问题；网站版本卡片可以展开查看历史版本与更新说明。
- `0.8.0` 增加匿名每日活跃统计，只有用户主动展开助手面板才计为当天活跃；新版可用或升级完成后，启动按钮显示 `NEW` 并在面板展示一次更新说明。
- `0.9.0` 支持直接在助手内投稿烂梗，可选择父子标签或建议新标签，并提供草稿保留、重复投稿和频率限制提示；点击助手以外区域可收起面板。
- `0.9.1` 将投稿页默认标签精简为前 5 个标签组，其余标签可按需展开或收起。
- `0.9.2` 存在严重性能 Bug：错误监听整个斗鱼页面的 DOM 更新，可能导致直播间卡死或无法打开，请勿使用。
- `0.9.3` 紧急修复 v0.9.2 全页面 DOM 监听造成的直播间性能问题，将恢复监听限制到助手直属节点，并避免无变化时重复计算位置。
- `0.9.4` 在标题栏增加网站首页入口，简化投稿按钮文字，并为面板展开与收起增加不依赖额外监听的轻量动效。
- 生产镜像会把脚本默认服务地址构建为 `https://9765366.cn`，接口路径仍使用 `/api`；源码继续保留本地默认值，方便开发。
- 在后端 `ALLOWED_ORIGINS` 中加入正式前端域名和斗鱼域名。
- 保留发送冷却，并根据真实访问量调整后端限流。
- 稳定版发布前必须按 [`release-process.md`](release-process.md) 完成本地候选测试；网站不公开旧版脚本下载入口。
