# ADR-002：斗鱼油猴脚本集成

状态：计划中
目标房间：`https://www.douyu.com/9765366`（溺水小龟）

## 目标

在直播间页面提供一个用户主动打开的“小龟烂梗”面板，支持搜索、复制、填入弹幕框和一键发送。

## 实现原则

- `@match` 匹配斗鱼直播间页面，助手可在任意房间使用，烂梗数据仍来自小龟实例。
- 搜索调用我们自己的只读 API，不复制参考项目的后端地址。
- UI 放入 Shadow DOM，避免斗鱼样式与脚本面板互相污染。
- 用 `MutationObserver` 等待播放器/聊天区域出现，不做 100ms 无限轮询。
- DOM 选择器集中在适配器中；斗鱼改版时只修改适配器。
- “填入”与“一键发送”分开；发送必须由用户明确点击触发。
- 一键发送按斗鱼当前发送间隔设置 3 秒本地冷却，不提供循环发送、自动刷屏或绕过平台限制。
- 复制成功后调用 `POST /api/memes/:id/copy`；发送可记录独立事件，但同一次操作不重复累计复制数。
- API 配置严格 CORS；脚本发布时锁定正式域名和版本。

## 推荐交互

1. 小龟图标打开侧边面板。
2. 每次展开面板或主动搜索时，保留当前关键词并请求 `GET /api/memes?query=...`。
3. 每条结果提供“复制”“填入”“发送”三个明确操作。
4. 填入弹幕框时触发原生 `input` 事件，兼容受控输入组件。
5. 找不到输入框或发送按钮时降级为复制，并提示斗鱼页面结构可能已更新。

## 参考与差异

参考脚本通过 `textarea.ChatSend-txt` 和 `div.ChatSend-button` 操作斗鱼页面，并设置发送冷却。该选择器属于脆弱实现，不能视为长期 API。参考脚本中的插件复制不会增加网站计数，我们的版本将补齐计数接口。
