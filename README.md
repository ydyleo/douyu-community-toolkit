# Douyu Community Toolkit

一个非官方的斗鱼水友社区工具项目，围绕圈内梗（inside jokes）、水友投稿、表情包、BGM 和直播间 Tampermonkey 助手展开。

本仓库当前以斗鱼主播“溺水小龟”的 `9765366` 直播间作为首个参考实现。前端使用 Nuxt 4、Vue 3 与 TypeScript，构建后由 Nginx 提供静态页面。

## 当前参考实现

| 项目 | 内容 |
| --- | --- |
| 主播 | 溺水小龟 |
| 斗鱼房间 | `9765366` |
| 实例名称 | 小龟烂梗补给站 |
| 计划域名 | `https://9765366.cn` |

站点名称、角色图片、默认内容、BGM 和素材目前都属于这个小龟实例。油猴助手可以出现在任意斗鱼直播间，但其烂梗内容仍来自小龟烂梗补给站。

本项目尚未做到“一键生成任意主播的独立站”。要适配其他主播，目前仍需替换站点配置、角色素材、默认内容、后端数据和部署配置；后续可以继续把这些内容抽离为多实例配置。

## 参考实现当前功能

- 浏览、搜索和按复制次数排序烂梗，首页每页展示 6 条并支持翻页
- 复制烂梗并记录复制次数
- 烂梗投稿、审核、后台增删改与复制统计
- 正式烂梗与浏览器本地暂存自动去重，重复投稿会被拦截
- 后台通过、新增、编辑或删除烂梗后，同浏览器中已打开的首页会自动同步；切回首页时也会再检查一次
- 表情包投稿审核、浏览、下载与后台管理
- 后台 BGM 上传、排序、上下架和删除
- 站长与管理员独立账号、密码修改、登录撤销和操作记录
- 可选择与关闭的背景音乐播放器
- 自定义小龟鼠标样式
- 支持任意斗鱼直播间、可拖动和可隐藏的油猴助手
- 油猴助手一键发送使用 3 秒本地冷却，不提供自动连发
- 每次展开油猴助手都会保留当前搜索词并重新获取最新烂梗

## 仓库边界

本公开仓库包含前端页面、公开静态资源、油猴脚本和 API 类型，不包含数据库、管理员凭证或后端实现。小龟实例的独立后端在开发者本地的另一个私有项目中维护。

因此，这个仓库目前既是 Douyu Community Toolkit 的前端原型，也是“溺水小龟 9765366”实例的实际前端，而不是已经完全通用化的开箱即用平台。

## 本地运行

运行当前小龟参考实例时，先启动相邻私有后端的 PostgreSQL 和 API，再运行本前端：

```bash
npm install
npm run dev
```

前端默认位于 `http://127.0.0.1:3000`，API 默认位于 `http://127.0.0.1:4000`。前端通过 `.env` 中的 `NUXT_PUBLIC_API_BASE` 切换 API 地址。

首次运行可复制示例配置：

```bash
cp .env.example .env
```

## 构建

```bash
npm run typecheck
npm run generate
```

静态产物输出到 `.output/public`，可以部署到 Nginx、对象存储或静态托管平台。Dockerfile 也只构建并托管前端，不包含后端和数据库。

正式环境使用 `https://9765366.cn`，浏览器通过同域名的 `/api` 访问后端。PostgreSQL 和后端容器均不直接暴露公网端口。

表情包与 BGM 的文件本体保存在后端持久化存储中，数据库保存标题、类型、审核状态、排序和统计信息。前端的 `public/` 素材只作为 API 不可用时的离线兜底。

## 目录

- `app/`：页面、样式、组合函数和 API 仓储
- `shared/`：公开数据类型与后端不可用时的占位内容
- `public/`：图片、音频和油猴脚本
- `deploy/`：前端 Nginx 配置
- `docs/`：架构决策与油猴助手说明

## 安全与数据边界

- 后台分为唯一站长和普通管理员；只有站长能创建、停用管理员或撤销其登录。
- 站长和管理员都可以在“账号与安全”中修改自己的密码。
- `shared/data/memes.ts`：后端不可用时显示的占位数据，上线前替换。
- `shared/types/meme.ts`：前端使用的 API 数据类型，不包含数据库实体。
- `app/composables/useApi.ts`：独立 API 客户端。
- `public/`：可公开的图片、音频与油猴脚本。
- 管理员账号、密码哈希、会话密钥和数据库地址全部只存在于后端项目。

不要提交 `.env`、私钥、数据库备份或任何生产凭证。GitHub Actions 会在每次推送时运行类型检查和静态构建。
